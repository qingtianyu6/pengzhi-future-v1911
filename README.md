# 棚智未来 · 设施农业智能监测与决策平台

棚智未来是一套面向设施农业生产管理的软件平台，将多源数据接入、环境预测、风险研判、番茄病害辅助识别、生产建议、农事任务和执行反馈连接为完整业务闭环。

## 五个一级工作台

- **智慧驾驶舱**：只负责运行总览，展示当前大棚、生育进程、关键环境指标、风险摘要和任务摘要。
- **数据中心**：统一管理大棚档案、种植批次、CSV/Excel 文件导入和第三方传感器 HTTP 接口。
- **智能研判**：集中完成历史趋势、未来 1～6 小时预测、数据健康度与风险事件分析。
- **病害识别**：番茄叶片六分类、Top-3 候选、置信度门控与人工复核。
- **生产闭环**：可解释建议、处置路径对比、任务执行与 AgriTrace 决策证据链。

AI 不占用一级导航。右下角的 **“棚小智”农业智能体**提供两种对话模式：

1. **通用问答**：不绑定大棚，检索本地农业知识库回答设施农业和平台使用问题；
2. **大棚对话**：绑定一个大棚，按问题读取该棚环境数据、1～6 小时预测、活动预警、农事任务和知识库后再回答。

## 数据接入

系统支持三类环境数据入口：

1. 页面导入 CSV / XLSX / XLSM；
2. 第三方传感器通过 `POST /api/v1/ingest/sensor-data` 直接上报；
3. 已有软件平台继续使用 `/api/sensors/batch` 批量写入标准化数据。

传感器接口按大棚编码接入，可配置 `SENSOR_INGEST_KEY` 并通过 `X-Sensor-Key` 请求头鉴权。系统不绑定具体硬件品牌。

文件导入前会进行字段识别、时间连续性、指标完整度、重复时间点和数值范围检查。没有可用环境记录时，各工作台保持空状态；环境预测满足连续历史数据要求后才会运行。

## 农业知识库

`backend/knowledge_base/knowledge.json` 保存棚小智的本地检索知识。当前覆盖：

- 设施蔬菜冬季/夏季温湿度与通风管理；
- 番茄叶霉病、早疫病、晚疫病、斑枯病、黄化曲叶病毒等风险要点；
- 设施甜瓜分阶段温湿度管理；
- 数据质量、传感器接入和 AI 决策安全边界。

农业条目保留公开来源机构和链接，回答用于生产信息整理与人工决策参考，不替代专业植保诊断。

## 算法能力

### 环境预测

环境预测引擎融合 Seasonal-24、GRU、LSTM、XGBoost 和基于验证结果的组合策略，并按变量和预测时长选择适合的方法。模型中心读取实际模型产物展示当前服务版本和验证指标。

### 病害辅助识别

病害识别采用 ResNet18 对番茄叶片六类状态进行辅助判断，输出 Top-3 候选结果。低置信结果进入人工复核，模型状态和指标直接读取模型产物。

## 本地运行

首次安装：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
```

开发模式：

```powershell
.\start_all.ps1
```

生产模式：

```powershell
.\start_production.ps1
```

生产模式访问 `http://127.0.0.1:8000`。

## Docker 部署

```bash
docker compose up -d --build
```

数据库和上传文件使用 Docker volume 持久化。

## 发布验证

```powershell
.\verify_release.ps1
```

验证脚本会依次执行后端测试、前端 Lint、前端生产构建和模型文件检查。

## 主要目录

- `frontend/`：React + TypeScript + Vite 前端
- `backend/`：FastAPI + SQLAlchemy + SQLite 后端
- `backend/knowledge_base/`：棚小智本地农业知识库
- `backend/app/ml/`：环境预测模型与推理代码
- `backend/app/artifacts/disease/`：病害识别模型产物
- `docs/`：架构、接口和数据库设计
