# 棚智未来农业知识库

本目录用于“棚小智”农业智能体的本地检索增强。知识条目以公开农业技术指导、大学推广机构资料和项目自身的产品规则为基础整理，内容用于信息检索和人工决策参考，不替代植保诊断、农技处方或设备控制指令。

知识库设计原则：

- 原文不直接大段复制，只保存经过项目整理的要点；
- 每条农业知识保留来源机构和公开链接；
- 对病害识别结果使用“候选结果/辅助判断”的表述；
- 涉及具体农药、剂量和高风险处置时，智能体只建议核实和咨询专业人员；
- `knowledge.json` 可继续扩充，后端无需新增向量数据库即可即时检索。

2026-10-16 扩充：保留原有10条，`knowledge_zh.json` 新增42条中文整理条目，来自20篇公开指导，合计52条（其中3条是平台数据/接入说明，49条是农业参考）。不是52本书或52篇论文。新增条目均保留适用条件、作物、主题、生育阶段和出处；整理主题不冒充原文段落编号。来源访问核验日志位于仓库 `.run/chinese-knowledge/knowledge-sources.json`。

两份JSON由统一检索服务合并加载，文件修改时间变化时刷新缓存，棚小智沿用同一检索入口，不建立第二套知识库。公共页提供主题分类和分页；组织上传文档仍需审核才能进入组织检索，互不泄露。
